# ClassicOldSong Tap

## How do I install these formulae?

`brew install classicoldsong/tap/<formula>`

Or `brew tap classicoldsong/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "classicoldsong/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
